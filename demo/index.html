dj-card-preview

The homepage hover preview from The DJ Calendar, extracted as a zero-dependency widget. Hover the card: a real 30-second iTunes preview plays, and the 8-bar EQ is driven by the audio's actual frequencies - not an animation pretending.

How to hear it: click anywhere on this page once (browsers require one gesture before any audio), then roll over the photo. The preview starts, the EQ dances to the real sound, and the overlay names the track. Roll off - or let the 30 seconds end - and everything stops.
You are now listening to: #1 David Guetta

No JavaScript frameworks. No build step. The lookup falls back to the live iTunes Search API when a card ships without a cached URL - the same call production makes for all 99 artists.
